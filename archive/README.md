# Archiwum — historyczne notatki robocze

**To nie jest dokumentacja produktu.** Katalog trzyma wczesne analizy i plany, które
zostały już zrealizowane albo zastąpione. Zawierają porównania do zewnętrznych firmware'ów
open source i odwołania do ich kodu — dlatego siedzą tutaj, a nie w `documentation/`.

Aktualne źródła prawdy:

- karty `FW-XXX` w `documentation/` — co i dlaczego zostało zrobione,
- `protocol/evistdrive_config_schema.yaml` — parametry konfiguracji,
- `CHANGELOG.md` — kolejność zmian i buildy,
- `documentation/RIDE_CORE_MASTER_CHECKLIST_PL.md` — stan toru wspomagania.

| Plik | Dlaczego archiwalny |
|---|---|
| `ASSIST_ANALYSIS_AND_ROADMAP.md` | pierwszy eksperyment ze wspomaganiem; zastąpiony przez RIDE_CORE_MASTER_CHECKLIST_PL i RIDE_CORE_STATUS_CANABLE |
| `EXPERIMENT_CAN_CANDIDATES.md` | kandydaci na parametry CAN; przeniesieni do `protocol/evistdrive_config_schema.yaml` |
| `PLAN_POWER_PATH_smooth_ride.md` | plan pisany na wersji 0.0114; cele zrealizowane strojeniami 0.0133/0.0134 i w Ride Core |
| `COMPARISON_SOC_range.md` | studium porównawcze SOC/zasięgu; wnioski wdrożone (FW-018, konfigurowalne progi) |
| `PLAN_walk_assist_speed_hold.md` | plan Walk Assist z lipca; zastąpiony przez FW-060/065/066/067 |

Treść zostaje bez zmian — przepisywanie analizy porównawczej tak, żeby nie nazywała
przedmiotu porównania, pozbawiłoby ją sensu. Jako materiał historyczny jest użyteczna
w oryginalnej postaci.
